**Technologies:** `Python` · `scikit-learn` · `pandas` · `matplotlib`

🔗 [ai-decision-tree-classification — Artificial Intelligence collection](https://github.com/zhrazaki/artificial-intelligence/tree/main/ai-decision-tree-classification)

| **Highlights** | 40×40 state buckets; exponential vs. fixed ε; average score −200 → ≈−160; ~−105-step evaluation episodes |

**Technologies:** `Python` · `gymnasium` · `numpy` · `matplotlib`

</details>

## 📚 Academic Coursework — Probability, Statistics & Data Analysis

<details>
<summary><b>📊 eps-statistical-distribution-analysis</b> &nbsp;—&nbsp; Distribution Recognition (Titanic dataset)</summary>

<br/>

> EDA of Titanic passenger features, marginalization, Q–Q plots against Normal / Log-normal / Exponential candidates, parameter estimation, binomial probability under a limited testing budget, plus a Monte-Carlo study of Poisson counting and the memoryless property.

**Technologies:** `R` · `plotly` · `Jupyter`

🔗 [eps-statistical-distribution-analysis — Statistics collection](https://github.com/zhrazaki/engineering-probability-and-statistics/tree/main/eps-statistical-distribution-analysis)

</details>

<details>
<summary><b>🎲 eps-random-variables-stochastic-models</b> &nbsp;—&nbsp; Stochastic Modeling</summary>

<br/>

> Sums of random variables (Gamma), loss-ratio distributions (Beta), covariance and autocorrelation analysis on real temperature data, and a discrete Markov belief model for robot localization (WALL-E) — all simulation-verified in R.

**Technologies:** `R` · `dplyr` · `ggplot2`

🔗 [eps-random-variables-stochastic-models — Statistics collection](https://github.com/zhrazaki/engineering-probability-and-statistics/tree/main/eps-random-variables-stochastic-models)

</details>

**Technologies:** `R` · `ggplot2` · `tidyr` · `gapminder`

🔗 [eps-clt-and-benfords-law — Statistics collection](https://github.com/zhrazaki/engineering-probability-and-statistics/tree/main/eps-clt-and-benfords-law)
